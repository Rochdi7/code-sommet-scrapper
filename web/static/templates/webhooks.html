How It Works

When an event fires, a POST request is sent to your webhook URL with:

  • Content-Type: application/json
  • X-Webhook-Event: {event name}
  • X-Webhook-Signature: sha256={hmac} (if secret is set)

Payload format:

{
  "event": "job.completed",
  "timestamp": "2025-01-15T10:30:00Z",
  "data": {
    "job_id": "...",
    "job_name": "...",
    "result_count": 42
  }
}

Webhooks are auto-disabled after 10 consecutive failures. Re-enable to reset the counter.
