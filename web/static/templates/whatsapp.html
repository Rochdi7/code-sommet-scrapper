WhatsApp

Send messages to leads
⚠ Use a secondary phone number. Bulk sending may get your WhatsApp account temporarily or permanently banned. CodeSommet is not responsible for any account restrictions.
How it works: For each recipient, the app launches whatsapp://send?phone=...&text=... — this opens WhatsApp Desktop with the chat and message pre-filled — then simulates an Enter keypress to send. Runs fully unattended between messages.
Requirements: WhatsApp Desktop installed and logged in on this machine. Do NOT use the mouse/keyboard while a campaign is running. The scraper binary must run natively on the host (not inside Docker) for keypress access.
